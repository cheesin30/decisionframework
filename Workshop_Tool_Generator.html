Workshop Tool Generator

Creates an exact, independent replica of the engagement-calendar tool for a new workshop — same wizard, QR, SharePoint save and safeguards — rebranded and reconfigured for that workshop. It works from the current tool file you give it, so every fix in the source carries over automatically.

1 · Source tool

Pick the current calendar tool file (e.g. LTI_Engagement_Calendar_QR_v1.html). The replica is derived from it.

2 · Workshop identity

Used everywhere the source says “Long-Term Investing” / “LTI”: page titles, the calendar name advisers see, filenames, the printed handout.

3 · Microsoft Form (optional now, needed before launch)

Paste this workshop's Form pre-fill link (Forms → Collect responses → Get pre-filled results, with a sample firm and date typed in). The generator maps the firm/date fields automatically. Leave blank to configure later inside the replica's Form settings.

4 · Default touchpoints

The sequence every consultant starts from (they can still edit per cohort). Pre-loaded with the source defaults.

5 · Generate

Builds the replica and downloads it. Every replacement is checked and listed — if the source has changed shape and an anchor can't be found, you'll see it here instead of getting a silently broken file.

The replica is fully independent: its own saved state (touchpoints, resources, folder pick), its own filenames and SharePoint folder — running it never interferes with the LTI tool or other workshops. Distribute it with the same consultant how-to; only the names differ.
